# Сайт-резюме Дениса Минишина

Статический сайт на Next.js App Router для GitHub Pages. Русская версия доступна по адресу `/`, английская — по `/en/`. Обе страницы создаются во время сборки; сервер Next.js на хостинге не нужен.

## Локальная разработка

Рекомендуется Node.js 26 LTS и pnpm версии, указанной в `package.json`. Поддерживается также Node.js 24. Например, установите эту версию pnpm и зависимости:

```sh
npm install --global pnpm@12.18.0
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который выведет Next.js, обычно `http://localhost:3000`. Для проверки изменений:

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm verify:export
```

Результат сборки находится в `out/`. Команда `build` также подготавливает оба адреса карточки предприятия и её метаданные. Каталог нужно отдавать обычным статическим HTTP-сервером; `next start` для этой конфигурации не используется. Docker также собирает статический сайт и раздаёт его через nginx: `docker compose up --build`, после чего сайт доступен на порту 8080.

Для проверки типов используется нативный компилятор TypeScript 7. Пакет `typescript` оставлен на совместимой версии TypeScript 6: он предоставляет JavaScript API инструментам, которым оно ещё необходимо. Такое параллельное использование описано в [документации TypeScript 7](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/). Типы Node.js соответствуют используемой в CI версии Node.js 26.

## Содержание и языки

- `src/data/resume-data-ru.tsx` и `src/data/resume-data-en.tsx` — тексты и данные резюме. Даты работы задаются в формате `YYYY-MM`; `end: null` означает текущую работу.
- `src/data/profile.ts` — общие для двух языков данные профиля и контакты.
- `src/lib/messages.ts` — подписи общих элементов интерфейса на двух языках. `src/components/resume-page.tsx` — общий шаблон обеих страниц.
- `src/lib/site.ts` — общие настройки и метаданные. `src/lib/dates.ts` содержит расчёт возраста и стажа: календарные месяцы пересекающихся мест работы не считаются дважды.
- `public/files/portfolio/` и `public/images/` — публичные файлы. `public/business-info.html` — отдельная статическая карточка предприятия; её содержимое редактируется в этом файле. В опубликованной сборке она доступна по адресам `/business-info.html` и `/business-info/`. Данные для копирования берутся из отображаемых полей карточки.

Стили построены на Tailwind CSS 4. Меню команд открывается кнопкой на странице или сочетанием Ctrl+K / ⌘+K.

Дата для возраста и стажа определяется по времени Красноярска. Сборка содержит начальное значение; в браузере с JavaScript оно обновляется автоматически. При отключённом JavaScript значение обновится после следующей сборки. Workflow запускается также ежедневно.

## Адрес сайта и переменные окружения

`SITE_URL` — необязательный публичный адрес для canonical URL, sitemap, robots.txt и метаданных карточки предприятия; по умолчанию используется `https://denis-minishin.ru`. Укажите HTTP(S)-адрес сайта без пути, параметров и учётных данных. При необходимости скопируйте `.env.example` в `.env.local` и измените адрес. Значение подставляется **во время сборки** и попадает в опубликованные страницы; секреты здесь хранить нельзя. Сам файл `.env.local` игнорируется Git.

Для GitHub Actions адрес можно задать переменной репозитория `SITE_URL` в **Settings → Secrets and variables → Actions → Variables**. Если домен меняется, обновите также `public/CNAME` и настройки домена в GitHub Pages; корневой `CNAME` сохранён для совместимости с прежней структурой.

Все файлы из `public/` доступны посетителям напрямую. В частности, карточка предприятия содержит персональные и банковские реквизиты и доступна по прямой ссылке. `noindex` и запрет индексации в `robots.txt` не ограничивают доступ к странице или PDF.

## Публикация

В настройках GitHub Pages выберите источник **GitHub Actions**. При изменениях в `master`, ручном запуске или по расписанию workflow проверяет проект, собирает статические файлы и публикует `out/`. Для pull request в `master` выполняются те же проверки без публикации. Версии GitHub Actions закреплены по commit SHA, а Dependabot предлагает обновления зависимостей и Actions.

В `pnpm-workspace.yaml` временно переопределена транзитивная версия `minimatch` для устранения [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249). Переопределение можно удалить после обновления зависимых инструментов; после этого следует повторить проверки проекта и `pnpm audit`.

Прежний неиспользуемый серверный GraphQL-маршрут удалён: GitHub Pages не исполняет его. Для API или аутентификации в будущем понадобится отдельный сервер или сервис.
